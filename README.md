# Brainiac Wizard Launcher

A Minecraft launcher with the Brainiac path-traced shader.

## ⬇ Download Brainiac Wizard Launcher

| Your system | Download (one file) |
|---|---|
| **Windows** (64-bit) | **[brainiac-wizard-windows-x86_64.zip](https://github.com/worldshapergame/brainiac-wizard/releases/download/live/brainiac-wizard-windows-x86_64.zip)** |
| **Linux** (x86_64) | **[brainiac-wizard-linux-x86_64.zip](https://github.com/worldshapergame/brainiac-wizard/releases/download/live/brainiac-wizard-linux-x86_64.zip)** |

### Install
1. Download the zip for your system and unzip it into its own folder.
2. Run the launcher inside it: `brainiac-wizard-launcher.exe` on Windows, `./brainiac-wizard-launcher` on Linux. Keep the folder whole.

### Updates
The launcher updates itself at each start from this page. If yours is older and Settings' **update address** is empty, put this there once:
`https://github.com/worldshapergame/brainiac-wizard/releases/download/live`

---
*The many files with long hex names under Assets are the updater's pieces; you never need to download them yourself.*
